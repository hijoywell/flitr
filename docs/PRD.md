# Flitr 产品需求文档 (PRD)

> **项目代号**：Flitr（源自 *Filter* 过滤 + *Flit* 轻快掠过）  
> **版本**：v1.0  
> **更新日期**：2026-11-11  
> **目标平台**：Android 11+（`minSdk = 30`），`targetSdk = 37`（Android 17），兼容主流国产 ROM：ColorOS / HyperOS / OriginOS / 鸿蒙兼容层 / 原生 Android  
> **设计语言**：Material Design 3 (Material You 动态色彩体系)

---

## 1. 产品背景与定位

### 1.1 痛点背景
当前移动端用户在日常使用中面临两类高频广告干扰：
1. **开屏广告高频打断**：冷启动或后台切回 App 时，频繁出现 3~5 秒开屏广告，“跳过”按钮往往热区极小、位置飘忽，甚至存在伪造跳过图标、全屏点击热区诱导跳转第三方电商/下载页的问题。
2. **短剧/短视频流广告打断沉浸体验**：以**红果短剧**等竖屏短剧/短视频 App 为代表，用户在解放双手连续追剧（如就餐、通勤、睡前支架观看）时，剧集间隙或推荐流中会穿插两类广告：
   - **无倒计时信息流广告**：可直接上滑跳过，但必须人工伸手划屏，打断观看连贯性；
   - **有倒计时激励/解锁广告**：必须等待 15s~30s 倒计时播完才能解锁下一集或允许划走；若提前划走则无效，播完后页面往往停留在广告尾帧或奖励弹窗页，不会自动切入下一集正片，中途还可能弹出“继续观看”拦截框。

### 1.2 产品定位
**Flitr** 是一款**纯本地运行、零联网权限、遵循 Material Design 3 美学**的 Android 智能无障碍辅助工具，聚焦两大核心能力：
1. **毫秒级无感跳过开屏广告**；
2. **短剧/短视频流广告智能托管（精准区分“无倒计时秒划”与“有倒计时播完自动划/关”）**。

## 2. 核心业务流程与场景详述

### 2.1 场景一：App 开屏广告自动跳过

```text
[监听到前台应用包名切换]
        │
        ▼
[是否在白名单/系统应用中？] ──是──► [忽略并休眠]
        │否
        ▼
[开启 6 秒开屏高敏检测时间窗]
        │
        ├─► 优先级1：命中内置广告 SDK 控件 ID（穿山甲/优量汇/快手联盟/百青藤等）
        ├─► 优先级2：命中该 App 专属自定义选择器规则
        └─► 优先级3：命中启发式语义（含“跳过”字样 + 控件面积 < 屏幕 12% + 非输入框）
                │
                ▼
        [执行节点点击 / 坐标微偏拟人点击]
                │
                ▼
        [记录本地日志 & 提前关闭时间窗进入低功耗待机]
```

**核心防误触约束**：
- **时间窗约束**：通用语义“跳过”仅在切入目标 App 后的前 `6秒`（可配置 `3~10秒`）内生效，避免用户在微信聊天、浏览器阅读含“跳过”文字的内容时发生误点。
- **防假按钮欺诈**：校验目标节点可点击区域的屏幕占比；若外层容器面积超过屏幕 `20%`（全屏广告诱导层），拒绝直接对大容器执行 `ACTION_CLICK`，仅在定位到真实小尺寸跳过区域时使用手势精准点按。
- **敏感场景绝对排除**：锁屏界面、系统权限弹窗、电话接听页、主流支付收银台（支付宝/微信支付 Activity）强制挂起。

### 2.2 场景二：视频流/短剧广告智能托管（以红果短剧为标杆）

针对红果短剧（`com.phoenix.read`）及同类竖屏视频流 App，广告形态复杂，需通过**状态机**精准处理：

#### 2.2.1 页面性质判定（正片 vs 广告）
| 维度 | 广告页判定特征（满足任一组合） | 正片保护特征（满足则严禁上滑） |
| :--- | :--- | :--- |
| **标识文案** | 出现 `广告`、`Sponsored`、`查看详情`、`立即下载`、`去看看`、`了解详情`、`点击安装`、`秒后可领奖/解锁` | 存在剧名+集数标识（如 `第 12 集`、`全xx集`）且无任何商业广告角标 |
| **交互组件** | 商业转化按钮卡片、顶部激励倒计时胶囊、右上角激励关闭区域 | 用户正在拖动底部进度条、正在打开“选集面板”或“评论弹幕输入区” |

#### 2.2.2 双分支核心处理逻辑

```text
[进入目标视频 App 新页面 / 视频切换]
        │
        ▼
[稳定帧观察期 Debounce 450ms]（等待异步 UI 节点与倒计时文案渲染完成）
        │
        ▼
[判定是否为广告页面？] ──否(正常剧集正片)──► [保持静默，不打扰用户看剧]
        │是
        ▼
[检测是否存在倒计时锁 / 激励计时特征？]
  （如 "15s"、"23秒后可领奖励"、"观看xx秒解锁"、"还剩xx秒"）
        │
        ├──► 【分支 A：无倒计时广告】
        │         │
        │         ▼
        │    [等待拟人反应延迟 350ms ~ 800ms]
        │         │
        │         ▼
        │    [执行拟人贝塞尔上滑手势，直接划去下一视频]
        │         │
        │         ▼
        │    [600ms 后校验页面是否切换成功，未切换则补偿重试 1 次]
        │
        └──► 【分支 B：有倒计时广告】
                  │
                  ▼
             [提取剩余秒数 T，进入 COUNTDOWN_WAITING 监听状态]
                  │
                  ├─► (异常插曲) 弹出“继续观看 / 放弃奖励”拦截框 ──► 自动点击「继续观看」
                  ├─► (异常插曲) 弹出“恭喜获得奖励 / 开心收下” ────► 自动点击收下/关闭
                  │
                  ▼
             [监听到倒计时归零 / 文案变为“已完成|已领取|可划走|跳过” / 出现关闭按钮 ×]
                  │
                  ├─► 形态1（全屏弹窗式激励视频）：优先点击「关闭 × / 跳过」返回剧集页
                  └─► 形态2（信息流内嵌式广告页）：等待 300~700ms 后执行「拟人上滑手势」划走
```

#### 2.2.3 人机协同与冲突避让机制
1. **手指触摸优先权（Touch Cooldown）**：一旦监测到用户手指主动触摸或滑动屏幕，Flitr 立即中止当前待执行的滑动任务，并进入 `3秒` 避让冷却期，绝不与用户“抢屏幕”。
2. **应用内微型悬浮胶囊（可选开启）**：
   - 基于无障碍原生图层（`TYPE_ACCESSIBILITY_OVERLAY`，**无需额外申请系统悬浮窗权限**），在红果短剧屏幕边缘展示胶囊指示器：
     - `⚡ 智划守护中`（半透明低存在感）
     - `⏳ 广告等待 12s`（实时同步倒计时进度）
     - `⏸ 已暂停托管`（用户单击胶囊可随时暂停/恢复，可拖拽贴边）

## 4. Material Design 3 界面与交互设计规范（参考 FlClash 视觉体系）

### 4.1 视觉风格定义 (FlClash Design DNA · M3 + Apple 混合美学)
- **表面层级与高对比色彩体系 (Surface & Vivid Palette)**：
  - **浅色模式（经典电光蓝 `#007AFF`）**：告别发闷的偏色灰底，采用清透冷灰页面底色（`Page #F0F2F6`）+ 纯净近白超圆角卡片（`Card #FFFFFF`）+ 卡片内嵌浅灰子容器（`Block #F3F5F8`），搭配鲜亮电光蓝主色 `#007AFF` 与翠绿运行胶囊（`#DCFCE7 / #15803D`）。
  - **高对比深色模式（暖珀橙 `#F59337` / 深海蓝 `#2E90FA`）**：参考 FlClash 高对比深色层级（`Page #12100E` ➔ `Card #1F1C19` ➔ `Block #2A2521` 逐级提亮而非下陷），在暗光追剧场景下层次分明、柔和护眼。
  - 同时内置 FlClash 同款多色圆点预设（电光蓝 `#007AFF`、星云紫 `#6362EA`、霓虹品红 `#FF2D55`、暖珀橙 `#F59337`、翠绿 `#34C759`）以及 Android 12+ 壁纸莫奈取色可选开关。
- **超圆角卡片与标志性微组件 (Shapes & Signature Widgets)**：
  - **超圆角 Bento 卡片**：移动端主卡片统一采用 `30dp~34dp` 连续超椭圆圆角，内部嵌套功能灰块采用 `20dp` 圆角，配合轻量柔和多层阴影。
  - **核心状态卡 + 12瓣星芒主控钮**：顶部主卡片右侧辅以柔和流体色块衬底，内嵌 FlClash 标志性的 **12 瓣星芒（M3 Cookie Shape）运行/暂停主按钮**。
  - **双栏波峰面积图 & 波浪进度条**：效率统计子卡片底部采用平滑三次贝塞尔渐变面积图；识别命中率与广告倒计时采用 M3 **波浪曲线进度条（`~~~~~`）**。
  - **悬浮毛玻璃胶囊底栏 (`Floating Glass Pill Dock`)**：底部导航栏脱离屏幕底边悬浮展示，带毛玻璃半透明背景与高光细描边。

### 4.3 核心页面交互细节

#### 页面 1：控制台 (Dashboard)
- **顶部服务主卡片**：
  - **未激活态**：采用 `SecondaryContainer` 柔和底色，主按钮显示「立即激活守护」，点击弹出底部引导面板（`ModalBottomSheet`），按步骤核对：① 解除受限设置（Android 13+ 侧载安装时自动提示） -> ② 开启无障碍服务 -> ③ 忽略电池优化。
  - **运行态**：采用 `PrimaryContainer` 主题色卡片，带有轻微呼吸感状态点。
- **双引擎快捷开关**：无需进二级页即可独立开关「开屏广告秒跳」与「视频流广告智划」。

#### 页面 2：场景规则 (Rules & Scenarios)
- 顶部采用 M3 **`SingleChoiceSegmentedButtonRow`（分段控制器）** 切换三个子视图：
  1. **`视频托管`**：
     - 置顶展示**「红果短剧」专属适配卡片**，点击展开 `ModalBottomSheet` 精细配置项：
       - 无倒计时广告：`立即划走（随机延迟 0.4~0.8s）`
       - 有倒计时广告：`等待倒计时归零后自动上滑 / 自动关闭弹窗`
       - 中途弹窗拦截：`自动点击“继续观看”`（默认开）
       - 悬浮状态胶囊：`在红果短剧边缘显示微型状态条`（默认开）
       - 视觉 OCR 增强：`针对无文本节点的混淆广告启用局部识别`（可选开关）
     - 右下角提供 M3 `ExtendedFloatingActionButton`（`+ 添加视频应用`），支持将抖音、快手、河马剧场等加入视频流托管。
  2. **`开屏跳过`**：内置通用规则库版本状态 + 按应用自定义规则列表。
  3. **`应用白名单`**：搜索并勾选完全不介入的应用（默认自动勾选系统桌面、电话、银行支付类 App）。

#### 页面 3：运行日志 (Activity Log)
- 按时间轴展示触发流水，每条记录包含：`应用图标 + 名称`、`触发时间`、`动作标签 Chip（如 [开屏跳过] / [无倒计时秒划] / [等15s后划走]）`、`命中的控件/文本摘要`。
- 左滑或点击菜单可选择 **「标记为误触」**，系统自动为该页面特征生成局部豁免规则。

#### 页面 4：设置 (Settings)
- **拟人防风控设置**：滑动耗时区间滑块（`RangeSlider`，默认 `180ms~320ms`）、反应延迟区间滑块（默认 `350ms~850ms`）、轨迹曲线随机抖动开关。
- **工作与保活增强**：持久前台通知开关、通知栏快捷磁贴（一键暂停/抓取快照）、可选 Shizuku 自动守护无障碍开关。
- **外观个性化**：跟随系统深浅色、Material You 动态取色开关、预设主题色圆点选择器。
- **数据与隐私**：规则与配置本地备份导出（JSON）、隐私承诺说明页（明确展示本应用未声明 `INTERNET` 权限，100% 纯离线运行）。

## 5. 非功能性需求与安全合规

1. **隐私安全（核心信任基石）**：
   - MVP 版本**不在 `AndroidManifest.xml` 中申请 `android.permission.INTERNET` 网络权限**，从系统底层证明绝无收集屏幕内容上传的可能（规则更新可通过系统文件选择器导入或通过外部浏览器下载分享给 Flitr）。
2. **性能与功耗指标**：
   - 待机静止状态下 CPU 占用率 `≈ 0%`；
   - 开屏跳过平均响应耗时 `< 200ms`；
   - 日均电量消耗占比 `< 0.8%`（严禁无节流全树遍历）。
3. **合规边界说明**：
   - 本工具仅面向个人用户辅助提升无障碍操作体验，通过标准 Android `AccessibilityService` API 实现，不注入、不破解、不修改任何第三方 App 内存或安装包数据，也不绕过付费墙逻辑（有倒计时的激励广告严格等待广告正常播放完毕后才辅助执行翻页操作）。

## 6. 版本迭代路线图 (Roadmap)

- **v0.1 (MVP 核心闭环)**：完成 MD3 框架搭建、无障碍服务保活引导、通用开屏广告跳过引擎、红果短剧「无倒计时秒划 + 有倒计时等完划走」节点树版状态机。
- **v0.2 (体验与防漏检升级)**：接入 Android 11+ 静默截图局部 OCR 兜底识别、应用内免权限悬浮状态胶囊、触发历史日志与一键误触拉黑。
- **v0.3 (生态扩展)**：上线通知栏「界面节点快照拾取器」、支持自定义 JSON 规则编辑与导入分享、接入可选 Shizuku 自动保活恢复能力。
